# 文档摘要技能

## 摘要原则
1. 保留核心论点和关键数据
2. 移除冗余示例和过渡语句
3. 按原文结构组织摘要
4. 中文文档用中文摘要，英文文档用英文摘要
5. 保持客观，不添加原文没有的评价

## 摘要格式

### 核心要点
- 用 3-5 个要点概括文档主旨

### 详细摘要
按原文章节顺序组织，每节用 1-2 句话概括

### 关键数据
- 提取文档中的具体数据点、配置项、版本号等

### 建议操作
- 基于文档内容给出 1-3 条可执行建议

## 注意事项
- 如果文档是代码，提取函数签名和关键逻辑
- 如果文档是配置文件，列出关键配置项和默认值
- 如果文档是 API 文档，提取端点列表和参数说明
