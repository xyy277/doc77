# Doc77 AI 使用指南

> 面向终端用户的 AI 工作台使用说明。

## 一、快速开始

### 1.1 配置 AI 模型

首次使用前，请在 **设置 → AI** 中配置：

| 字段 | 说明 | 示例 |
|------|------|------|
| Base URL | OpenAI 兼容 API 地址 | `http://192.168.110.39:1234/v1` |
| API Key | 密钥（本地模型可填 `sk-anything`） | `sk-anything` |
| Model | 模型名称 | `qwen2.5-7b-instruct` |
| Risk Level | 允许 AI 执行的操作级别 | `low` / `medium` / `high` |

**风险级别说明**：

- **low** — 仅允许 AI 创建文件夹，其他写操作需审批
- **medium** — 允许 AI 创建文件夹、移动文件（默认）
- **high** — 允许 AI 写入文件、删除文件（所有操作均需审批）

> ⚠️ 所有写操作都会进入**审批队列**，你可以在「审批」标签页确认或拒绝，AI 不会直接修改你的文件。

### 1.2 打开 AI 工作台

三种方式进入 AI 工作台：

1. 仪表盘顶部点击 **🤖 AI** 按钮
2. 文档预览页右栏点击 **「在 AI 工作台打开」**
3. 直接访问 `http://your-host:port/ai`

## 二、多会话管理

### 2.1 创建新会话

- 点击侧栏顶部 **「新对话」** 按钮
- 或直接在输入框输入消息，系统会自动创建会话

### 2.2 会话列表

左侧边栏按时间分组显示所有会话：

- **📌 置顶** — 你手动置顶的会话
- **今天** / **昨天** / **本周** / **本月** / **更早**

每个会话行支持三个操作：

| 图标 | 操作 | 说明 |
|------|------|------|
| 📌 | 置顶/取消置顶 | 置顶的会话始终显示在最前 |
| 🗄 | 归档 | 移到归档区，不删除 |
| 🗑 | 删除 | 软删除（可恢复） |

### 2.3 搜索会话

在侧栏搜索框输入关键词，系统会搜索会话标题和消息内容。

### 2.4 多 Tab 切换

工作台支持同时打开多个会话标签页：

- 点击 Tab 切换会话
- 点击 Tab 上的 **✕** 关闭
- Tab 状态自动持久化到浏览器，刷新页面后恢复

## 三、对话分支

Doc77 AI 支持树状对话结构——你可以随时编辑历史消息或重新生成回复，不会丢失原始对话。

### 3.1 重新生成回复

将鼠标悬停在 AI 回复上，点击 **「重新生成」** 按钮。系统会：

1. 保留原始回复（作为分支 v1）
2. 重新调用模型生成新回复（分支 v2）
3. 自动切换到新分支

### 3.2 编辑消息重发

将鼠标悬停在你发送的消息上，点击 **「编辑」** 按钮：

1. 修改消息内容
2. 发送后，系统创建一个新的兄弟消息（新分支）
3. 原始消息保留

### 3.3 切换分支

当一条消息有多个版本时，下方会出现分支切换器：

```
‹  2/3  ›
```

- **‹** — 切换到上一个分支
- **2/3** — 当前是第 2 个分支，共 3 个
- **›** — 切换到下一个分支

切换分支后，后续对话也会跟随切换。

## 四、工具与审批

### 4.1 AI 可用的工具

AI 可以调用以下工具来探索和操作你的文档：

**只读工具（自动执行）**：

| 工具 | 说明 |
|------|------|
| `list_files` | 列出目录内容 |
| `read_file` | 读取文件内容 |
| `get_file_info` | 获取文件元信息 |
| `list_projects` | 列出所有项目 |
| `search_files` | 搜索文件 |

**写工具（需审批）**：

| 工具 | 说明 | 最低风险级别 |
|------|------|-------------|
| `create_folder` | 创建文件夹 | low |
| `move_file` | 移动/重命名文件 | medium |
| `batch_operations` | 批量操作 | medium |
| `write_file` | 写入文件内容 | high |
| `delete_file` | 删除文件（不可逆） | high |

### 4.2 审批流程

1. AI 调用写工具 → 提案进入审批队列
2. 你在「审批」标签页看到待处理任务
3. **确认** → 事务执行器执行操作（支持回滚）
4. **拒绝** → 操作取消

### 4.3 敏感文件保护

以下文件 AI **永远无法**操作（无论风险级别）：

- `.env` 文件
- `*.key` / `*.pem` 密钥文件
- 其他通过 `isSensitiveFile()` 判定的文件

## 五、实时控制

### 5.1 停止生成

AI 回复过程中，发送按钮变为 **⏹ 停止** 按钮。点击后：

- 模型立即停止生成
- 已生成的内容保留
- 工具调用如果正在执行，会完成当前步骤后停止

### 5.2 注入指令（高级）

在 AI 使用工具的过程中，你可以通过 API 注入额外指令：

```bash
POST /api/ai/chat/interrupt
{
  "session_id": "your-session-id",
  "type": "inject",
  "message": "也检查一下子目录"
}
```

注入的指令会追加到模型上下文，不中断当前执行。

## 六、上下文管理

长对话会自动压缩，确保不会超出模型上下文窗口：

| 阶段 | 触发条件 | 处理方式 |
|------|---------|---------|
| Tool Result Budget | 单条工具结果过长 | 截断到 4000 字符 |
| Snip Compact | 超过 10 轮对话 | 移除中间历史，保留首尾 |
| Microcompact | 工具输出超长 | 压缩为摘要 |
| Auto-Compact | 达到窗口 70% | LLM 生成完整摘要 |

压缩时会在对话中显示通知：`上下文已压缩：摘要了 N 条消息`

## 七、Skill 系统

### 7.1 什么是 Skill

Skill 是可复用的 AI 能力包，类似 Claude Code 的 SKILL.md 机制。每个 Skill 定义：

- **触发条件** — 何时使用这个技能
- **指令内容** — 技能加载后注入的完整提示
- **适用范围** — 哪些文件/场景适用

### 7.2 内置 Skill

Doc77 自带以下技能：

| 技能 | 说明 |
|------|------|
| `doc-summarize` | 文档摘要生成 |
| `doc-translation` | 文档翻译 |
| `doc-lint` | 文档格式检查 |
| `project-init` | 项目结构分析 |

### 7.3 管理 Skill

在工作台右侧点击 **⚡** 打开技能抽屉：

- **开关** — 启用/禁用单个技能
- **🔄 重新扫描** — 重新加载技能文件
- **始终注入** — 标记为 `alwaysApply` 的技能会自动注入每次对话

### 7.4 自定义 Skill

参见 [Skill 开发指南](./ai-skill-dev-guide.md)。

## 九、常见问题

### Q: AI 报错 "Model not set"

A: 请先在 **设置 → AI** 中配置模型。

### Q: AI 不调用工具，只给文字建议

A: 本地小模型（如 3B）可能不支持 `tool_calls`。建议使用 7B 以上的模型。

### Q: 对话中断后能恢复吗？

A: 可以。所有消息实时持久化到数据库。刷新页面后，重新打开会话即可看到完整历史。

### Q: 如何删除所有对话数据？

A: 在数据库中执行 `DELETE FROM ai_sessions`（谨慎操作，不可恢复）。
